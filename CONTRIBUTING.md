# Contributing to FRAMEFORGE

Thank you for helping improve FRAMEFORGE. Bug reports, prompt-behavior observations, translations, design feedback, and pull requests are welcome.

## Before opening an issue

- Search existing issues for the same problem.
- Confirm the problem still occurs on the latest `main` branch.
- Remove personal data, private URLs, API keys, reference images, and generated media that you do not have permission to share.
- State the browser, device, operating system, and generation mode when relevant.

For prompt-behavior feedback, include the relevant generated FRAMEFORGE prompt excerpt, the expected result, and the actual result. Do not attach illegal material or content involving minors.

## Pull requests

1. Create a focused branch from `main`.
2. Keep unrelated changes out of the pull request.
3. Run `npm run lint` and `npm test`.
4. Explain the user-visible impact and how you verified it.

All additions must preserve the adults-only, clearly consensual scope of the project.
